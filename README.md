# Codex — Library Management System

A C++ console application for managing a library's books,
members, and transactions using core OOP principles.

## Features
- Add, search, and remove books
- Register and manage members
- Issue and return books
- Track transaction history

## Concepts Used
- Encapsulation, Inheritance, Polymorphism
- Operator Overloading
- Class-based architecture

## How to Run
1. Clone the repo
2. Compile: g++ main.cpp -o codex
3. Run: ./codex

## Tech Stack
- Language: C++
- Compiler: g++
